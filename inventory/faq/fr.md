## ❓ Questions fréquentes

Nous avons rassemblé ici les questions les plus fréquentes et leurs réponses.

---

### 📦 À propos du Papier (Paper)

<details open>
<summary><strong>Q. Qu'est-ce que le Papier ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Le Papier est une monnaie interne de l'application utilisée pour créer des objets.
<ul>
<li>Créer 1 objet = 1 feuille de Papier consommée</li>
<li>10 feuilles offertes à l'inscription</li>
<li>Achat supplémentaire possible dans la boutique</li>
</ul>
</div>
</details>

<details>
<summary><strong>Q. Peut-on obtenir du Papier gratuitement ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui ! Vous pouvez en obtenir gratuitement des façons suivantes :
<ul>
<li><strong>Inscription</strong> : 10 feuilles offertes (une seule fois)</li>
<li><strong>Liaison du compte Google</strong> : +10 feuilles</li>
<li><strong>Liaison du compte Apple</strong> : +10 feuilles</li>
</ul>
En liant tous vos comptes sociaux, vous pouvez recevoir jusqu'à 30 feuilles gratuitement.
</div>
</details>

<details>
<summary><strong>Q. Que faire si je n'ai plus de Papier ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Sans Papier, vous ne pouvez plus créer de nouveaux objets. Achetez du Papier dans la boutique ou, si vous avez un compte social non encore lié, liez-le pour en obtenir davantage.
<br><br>
Les objets déjà créés restent conservés même sans Papier.
</div>
</details>

### 📄 Création d'objets

<details>
<summary><strong>Q. Comment créer un objet ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Il existe deux façons de créer un objet :
<ol>
<li><strong>Copier un élément de base</strong> : Trouvez dans Explorer un élément de base qui vous plaît, puis appuyez sur le bouton <strong>Découper</strong> de l'écran de détail — 1 feuille de Papier est consommée et une copie est créée dans votre inventaire</li>
<li><strong>Créer un tampon</strong> : Sélectionnez un tampon vierge et utilisez <strong>« Créer un tampon »</strong> pour réaliser un tampon personnel avec sa propre page d'informations</li>
</ol>
L'ancienne fonction « Créer un nouvel objet » (rédaction à partir de zéro) a été supprimée. Les objets déjà créés restent conservés et utilisables.
</div>
</details>

<details>
<summary><strong>Q. Peut-on définir une date d'expiration pour un objet ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui, lors de l'édition dans « Créer un tampon », vous pouvez définir les dates suivantes :
<ul>
<li><strong>Date de début</strong> : Le contenu est flouté jusqu'à cette date</li>
<li><strong>Date d'expiration</strong> : Passé cette date, le contenu est flouté et l'ajout de journaux devient impossible</li>
</ul>
Sans réglage, le contenu est publié immédiatement et conservé de façon permanente.
</div>
</details>

<details>
<summary><strong>Q. Peut-on supprimer un objet ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui, sélectionnez l'objet puis supprimez-le depuis le menu inférieur.
<br><br>
⚠️ <strong>Attention</strong> :
<ul>
<li>Les objets supprimés ne peuvent pas être récupérés</li>
<li>Le Papier (Paper) ne peut pas être supprimé</li>
<li>Les consommables inutilisés (encre, tampon, badge) ne peuvent pas non plus être supprimés</li>
<li>Un badge équipé doit d'abord être retiré avant de pouvoir être supprimé</li>
</ul>
</div>
</details>

### 🏷️ Système de badges

<details>
<summary><strong>Q. Qu'est-ce qu'un badge ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Le badge est votre <strong>identité unique</strong> au sein de l'application.
<br><br>
Lorsque vous gravez un nom de domaine sur un badge, toutes vos activités dans l'application affichent le <strong>nom de domaine gravé</strong> au lieu de votre adresse e-mail.
<br><br>
Exemple : <code>MyBrand</code>, <code>JeanDupont</code>
</div>
</details>

<details>
<summary><strong>Q. Comment graver un badge ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Suivez ces étapes :
<ol>
<li>Sélectionnez un badge inutilisé → menu <strong>« Graver »</strong></li>
<li>Saisissez le nom de domaine souhaité (32 caractères max., lettres/chiffres uniquement)</li>
<li>Vérifiez sa disponibilité avec le bouton <strong>« Vérifier la disponibilité du domaine »</strong></li>
<li>Joignez éventuellement une image 128x128</li>
<li>Terminez avec le bouton <strong>« Graver »</strong></li>
</ol>
⚠️ <strong>Important</strong> : Une fois gravés, le nom de domaine et l'image sont <strong>définitivement non modifiables</strong>.
</div>
</details>

<details>
<summary><strong>Q. Comment équiper/retirer un badge ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Touchez un badge gravé : les boutons <strong>« Équiper »</strong> et <strong>« Retirer »</strong> apparaissent sur l'écran de détail.
<ul>
<li><strong>Équiper</strong> : Toutes vos activités dans l'application affichent le nom de domaine gravé</li>
<li><strong>Retirer</strong> : Votre adresse e-mail par défaut est de nouveau affichée</li>
</ul>
Même si vous possédez plusieurs badges, un seul peut être équipé à la fois.
</div>
</details>

<details>
<summary><strong>Q. Quelqu'un d'autre peut-il utiliser le même nom de domaine ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Non. Le nom de domaine doit être <strong>unique</strong> parmi tous les utilisateurs.
<br><br>
Cependant, si le badge est supprimé, le nom de domaine est libéré et peut être utilisé par quelqu'un d'autre.
</div>
</details>

### 🔖 Système de tampons

<details>
<summary><strong>Q. Qu'est-ce qu'un tampon ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Le tampon est un objet qui permet de créer un <strong>tampon personnel</strong> et de le transmettre à d'autres personnes.
<br><br>
Un tampon personnel peut recevoir une image, un titre, un contenu, une date d'expiration, etc., et la <strong>fonction journal</strong> permet d'y consigner des notes.
</div>
</details>

<details>
<summary><strong>Q. Comment créer un tampon personnel ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Suivez ces étapes :
<ol>
<li>Sélectionnez un tampon vierge inutilisé → menu <strong>« Créer un tampon »</strong></li>
<li>Saisissez le <strong>nom</strong> du tampon (32 caractères max.) — il ne pourra plus être modifié après confirmation</li>
<li>Dans l'éditeur qui s'ouvre ensuite, disposez images, textes et éléments pour composer la page d'informations</li>
<li>Réglez les options : date de début/date d'expiration, <strong>mode journal</strong> (journal solo/journal partagé), etc.</li>
<li>Enregistrez, c'est terminé</li>
</ol>
</div>
</details>

<details>
<summary><strong>Q. Quelle est la différence entre journal solo et journal partagé ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Le mode journal change complètement la façon d'enregistrer :
<br><br>
<table>
<tr><th>Catégorie</th><th>Journal solo</th><th>Journal partagé</th></tr>
<tr><td>Stockage des journaux</td><td>Dans l'espace privé de chacun</td><td>Dans l'espace partagé du tampon original</td></tr>
<tr><td>Journaux visibles</td><td>Uniquement vos propres journaux</td><td>Journaux de tous les propriétaires</td></tr>
<tr><td>Exemples d'usage</td><td>Journal intime, notes</td><td>Travail collaboratif, échange d'avis, communauté</td></tr>
<tr><td>Si le tampon est supprimé</td><td>Aucun impact</td><td>Ajout au journal partagé impossible (lecture seule)</td></tr>
</table>
</div>
</details>

<details>
<summary><strong>Q. Peut-on dupliquer un tampon ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui ! En sélectionnant ensemble un tampon activé (tampon personnel) et du Papier, le menu <strong>« Dupliquer »</strong> apparaît.
<br><br>
La duplication consomme 1 feuille de Papier et crée un nouvel objet au contenu identique. En mode journal partagé, il utilise le même espace partagé que l'original.
</div>
</details>

### ⚡ Saisie rapide (Quick Input)

<details>
<summary><strong>Q. Qu'est-ce que Quick Input ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Quick Input est une fonction qui facilite la saisie d'informations spéciales lors de la rédaction d'un journal.
<br><br>
Appuyez sur le bouton <strong>+</strong> à côté du champ de saisie du journal pour choisir parmi les types suivants :
<ul>
<li><strong>Mot-clé</strong> : Format général clé:valeur</li>
<li><strong>Alarme de date</strong> : Carte de date (calcul automatique du D-Day)</li>
<li><strong>Numéro de téléphone</strong> : Formatage automatique selon le pays</li>
<li><strong>Position</strong> : Adresse/lieu</li>
<li><strong>Montant</strong> : Devise et montant</li>
</ul>
</div>
</details>

<details>
<summary><strong>Q. Que se passe-t-il lors d'un appui long sur une carte spéciale ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> L'action exécutée dépend du type de carte :
<ul>
<li><strong>📅 Date</strong> : Activer/désactiver l'alarme</li>
<li><strong>📞 Numéro de téléphone</strong> : Appel direct sur mobile, copie sur ordinateur</li>
<li><strong>📍 Position</strong> : Ouverture de l'app de cartes sur mobile, copie sur ordinateur</li>
<li><strong>💰 Montant</strong> : Copie dans le presse-papiers</li>
</ul>
</div>
</details>

<details>
<summary><strong>Q. Comment définir une alarme sur une date ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> <strong>Appuyez longuement</strong> sur la carte de date : une boîte de dialogue de confirmation d'alarme apparaît.
<br><br>
Une fois l'alarme activée, la couleur de la carte change et une icône 🔔 s'affiche. Un nouvel appui long désactive l'alarme.
<br><br>
💡 Le D-Day est calculé automatiquement sur les cartes de date (ex. : D-5, D-Day, D+3)
</div>
</details>

### 📝 Fonction journal

<details>
<summary><strong>Q. Qu'est-ce qu'un journal ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Le journal est la fonction qui permet de consigner des notes sur un objet ou un tampon personnel.
<br><br>
Rédigé sous forme de message, il s'affiche comme une discussion ; rédigé au format <code>clé:valeur</code>, il s'affiche comme une carte d'information.
</div>
</details>

<details>
<summary><strong>Q. Existe-t-il des formats spéciaux pour les journaux ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui, plusieurs formats sont pris en charge :
<br><br>
<strong>Formats de base :</strong>
<ul>
<li><code>clé:valeur</code> - Affiché comme carte d'information (clé de 1 à 8 caractères)</li>
<li><code>---</code> - Affiché comme séparateur</li>
<li>Texte normal - Affiché comme bulle de discussion</li>
</ul>
<strong>Styles de texte :</strong>
<ul>
<li><code>{[texte]}</code> - Carte couleur principale</li>
<li><code>[{texte}]</code> - Carte grise + texte couleur principale</li>
<li><code>[texte]</code> - Carte grise</li>
<li><code>{texte}</code> - Texte couleur principale</li>
<li><code>(texte)</code> - Texte couleur secondaire</li>
<li><code>"texte"</code> - Gras</li>
<li><code>'texte'</code> - Souligné</li>
<li><code>&lt;texte&gt;</code> - Barré</li>
</ul>
Les styles peuvent être imbriqués jusqu'à 3 niveaux. Si la même clé est utilisée plusieurs fois, une comparaison s'affiche au format <code>ancienne valeur → nouvelle valeur</code>.
</div>
</details>

<details>
<summary><strong>Q. Un message indique que le journal partagé est interrompu</strong></summary>
<div class="answer-content">
<strong>A.</strong> L'ajout au journal partagé est interrompu dans les cas suivants :
<ul>
<li><strong>Suppression du tampon original</strong> : « Le tampon original a été supprimé, le journal partagé est interrompu »</li>
<li><strong>Date d'expiration dépassée</strong> : « Impossible d'ajouter des journaux à un journal partagé expiré »</li>
</ul>
Les journaux existants restent lisibles, mais aucun nouveau journal ne peut être ajouté.
</div>
</details>

<details>
<summary><strong>Q. Qu'est-ce que l'encre ?</strong></summary>
<div class="answer-content">

<li><strong>Encre dorée</strong> : Thème doré élégant</li>

</div>
</details>

### 📎 Système de clips

<details>
<summary><strong>Q. Qu'est-ce qu'un clip ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Le clip est une fonction qui regroupe plusieurs documents en un seul ensemble.
<ul>
<li>Gérez les documents liés entre eux comme un seul lot</li>
<li>Les documents clipés affichent une icône 📎 en haut à droite</li>
<li>Lors d'un envoi, ils se déplacent ensemble en tant que lot</li>
</ul>
</div>
</details>

<details>
<summary><strong>Q. Comment créer un clip ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Suivez ces étapes :
<ol>
<li>Sur l'écran d'accueil, sélectionnez <strong>2 documents ou plus</strong></li>
<li>Choisissez <strong>« Regrouper en clip »</strong> dans le menu inférieur</li>
<li>Les documents sélectionnés sont regroupés en un seul clip</li>
</ol>
💡 <strong>Astuce</strong> : Le premier document sélectionné devient la <strong>couverture</strong> du clip !
</div>
</details>

<details>
<summary><strong>Q. Comment changer l'ordre des objets dans un clip ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Sur l'écran de détail d'un objet clipé, touchez le bouton <strong>« Infos du clip »</strong> : la liste des objets du clip apparaît.
<br><br>
<strong>Faites glisser</strong> les objets pour les réordonner comme vous le souhaitez.
<br><br>
⚠️ <strong>Attention</strong> : La couverture (premier objet) ne peut pas être déplacée.
</div>
</details>

<details>
<summary><strong>Q. Comment retirer un objet d'un clip ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Sur l'écran des infos du clip, sélectionnez l'objet à retirer puis touchez <strong>« Retirer du clip »</strong>.
<br><br>
L'objet retiré redevient un document individuel.
<br><br>
⚠️ <strong>Attention</strong> :
<ul>
<li>La couverture ne peut pas être retirée</li>
<li>S'il ne reste que 2 objets dans le clip et que vous en retirez 1, le clip est automatiquement dissous</li>
</ul>
</div>
</details>

<details>
<summary><strong>Q. Comment dissoudre complètement un clip ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Sélectionnez l'objet clipé puis touchez <strong>« Dissoudre le clip »</strong> dans le menu inférieur : tous les objets redeviennent des documents individuels.
</div>
</details>

<details>
<summary><strong>Q. Que se passe-t-il lorsqu'on envoie un clip ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Le clip est envoyé <strong>en tant que lot</strong>.
<ul>
<li>Tous les objets du clip sont envoyés ensemble</li>
<li>L'état de clip est conservé dans l'inventaire du destinataire</li>
<li>Sur l'écran de réception, le clip est compté comme <strong>1</strong> élément</li>
</ul>
</div>
</details>

### 📤 Envoyer/Recevoir

<details>
<summary><strong>Q. Un objet envoyé disparaît-il de mon inventaire ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui, immédiatement. L'envoi est irréversible, procédez donc avec précaution.
<br><br>
Cependant, si le destinataire choisit <strong>« Renvoyer »</strong>, l'objet vous revient.
</div>
</details>

<details>
<summary><strong>Q. Où trouver le code QR ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Vous pouvez consulter votre code QR sur l'écran <strong>Profil</strong>.
<ul>
<li>Expéditeur : Scannez le code QR du destinataire avec le bouton <strong>« Scanner un QR »</strong></li>
<li>Destinataire : Montrez le code QR de votre profil</li>
</ul>
Le code QR contient l'adresse e-mail, ce qui permet un envoi rapide sans saisie manuelle.
</div>
</details>

<details>
<summary><strong>Q. Peut-on envoyer plusieurs objets à la fois ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui, c'est possible. Cochez plusieurs objets sur l'écran d'envoi puis envoyez-les en une seule fois.
</div>
</details>

### 🔍 Fonction de recherche

<details>
<summary><strong>Q. Comment utiliser la barre de recherche ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Touchez la barre de recherche en haut pour activer le mode recherche :
<ul>
<li>Les résultats sont filtrés <strong>en temps réel</strong> pendant la saisie</li>
<li>Les <strong>recherches récentes</strong> s'affichent en dessous (5 max.)</li>
<li>Le bouton <strong>« Définir comme filtre »</strong> enregistre le terme pour une réutilisation rapide</li>
</ul>
</div>
</details>

<details>
<summary><strong>Q. Comment gérer les filtres ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Lorsqu'un terme de recherche est enregistré comme filtre :
<ul>
<li>Il s'affiche sous forme de tag de filtre sous la barre de recherche</li>
<li>Touchez le tag pour filtrer immédiatement avec ce terme</li>
<li>Supprimez le filtre avec le bouton X</li>
</ul>
</div>
</details>

<details>
<summary><strong>Q. Qu'est-ce que l'agrégation de mots-clés ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Lorsque vous sélectionnez des objets avec un filtre actif, les valeurs de leurs mots-clés sont automatiquement agrégées :
<ul>
<li><strong>Valeurs numériques</strong> : Somme et moyenne calculées (ex. : <code>Somme : 6000  Moyenne : 2000</code>)</li>
<li><strong>Valeurs textuelles</strong> : Concaténées avec des espaces (ex. : <code>A B C</code>)</li>
<li><strong>Copier la valeur</strong> : <strong>Appuyez longuement</strong> sur la carte de résultat pour la copier dans le presse-papiers</li>
</ul>
Pratique pour calculer le total des prix de plusieurs objets ou rassembler des tags associés.
</div>
</details>

### 📂 Pocket

<details>
<summary><strong>Q. Qu'est-ce qu'une Pocket ?</strong></summary>
<div class="answer-content">

### 📱 Compte/Synchronisation

<details>
<summary><strong>Q. Puis-je voir mes objets sur d'autres appareils ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui ! En vous connectant avec le même compte, vos objets sont synchronisés automatiquement sur tous vos appareils.
<ul>
<li><strong>Synchronisation en temps réel</strong> : Les modifications sont répercutées immédiatement sur les autres appareils</li>
<li><strong>Sauvegarde cloud</strong> : Toutes les données sont stockées en sécurité dans le cloud</li>
<li><strong>Aucune limite d'appareils</strong> : Utilisation simultanée possible sur plusieurs appareils</li>
</ul>
</div>
</details>

### 🖼️ Images

<details>
<summary><strong>Q. Y a-t-il des limites de taille ou de format pour les images ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Les limites suivantes s'appliquent :
<ul>
<li><strong>Formats pris en charge</strong> : JPG, PNG, GIF, WebP</li>
<li><strong>Taille maximale</strong> : 10 Mo par image</li>
<li><strong>Dimensions recommandées</strong> : 1024x1024 ou moins (redimensionnement automatique)</li>
</ul>
Les images haute résolution sont automatiquement optimisées avant l'enregistrement.
</div>
</details>

<details>
<summary><strong>Q. Qu'est-ce que la suppression d'arrière-plan par IA ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> C'est une fonction de l'éditeur d'images où l'IA supprime automatiquement l'arrière-plan.
<ul>
<li>Lors de la sélection d'une image d'objet, touchez le bouton <strong>« Modifier »</strong></li>
<li>Choisissez l'option <strong>« Supprimer l'arrière-plan »</strong></li>
<li>L'IA reconnaît automatiquement le sujet principal et rend l'arrière-plan transparent</li>
</ul>
Idéal pour obtenir un résultat net sur des photos de produits ou de personnes.
</div>
</details>

### 🔔 Notifications

<details>
<summary><strong>Q. Comment désactiver ou configurer les notifications ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Vous pouvez les gérer dans les réglages système de votre appareil :
<ul>
<li><strong>iOS</strong> : Réglages → Notifications → Inventory</li>
<li><strong>Android</strong> : Paramètres → Applications → Inventory → Notifications</li>
<li><strong>macOS</strong> : Réglages Système → Notifications → Inventory</li>
</ul>
Pour désactiver une alarme de date individuelle, appuyez longuement sur la carte de date concernée.
</div>
</details>

<details>
<summary><strong>Q. Quand l'alarme D-Day se déclenche-t-elle ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Une notification push est envoyée à <strong>9 h du matin</strong> le jour de la date définie.
<br><br>
💡 <strong>Astuce</strong> : Pour les échéances importantes, créez plusieurs cartes de date (D-7, D-3, D-1, etc.) afin d'être rappelé à l'avance.
</div>
</details>

### 🔒 Sécurité/Confidentialité

<details>
<summary><strong>Q. Où mes données sont-elles stockées ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Toutes les données sont stockées en sécurité dans le <strong>cloud Firebase</strong>.
<ul>
<li><strong>Transfert chiffré</strong> : Toutes les communications sont chiffrées en TLS</li>
<li><strong>Stockage sécurisé</strong> : Géré sur l'infrastructure Google Cloud</li>
<li><strong>Protection de la vie privée</strong> : Les autres utilisateurs ne peuvent pas accéder à vos objets</li>
</ul>
Pour en savoir plus, consultez la <a href="/inventory/privacy/">politique de confidentialité</a>.
</div>
</details>

<details>
<summary><strong>Q. Existe-t-il une fonction de verrouillage des documents ?</strong></summary>
<div class="answer-content">
<strong>A.</strong> Oui ! Vous pouvez <strong>verrouiller</strong> un objet.
<ul>
<li>Écran de détail de l'objet → menu inférieur → <strong>« Verrouiller »</strong></li>
<li>Le contenu des objets verrouillés est flouté</li>
<li>Pour le consulter, une authentification de l'appareil (Face ID, empreinte, code PIN) est requise</li>
</ul>
Vous pouvez ainsi conserver vos informations sensibles en toute sécurité.
</div>
</details>

<summary><strong>Q. À quoi peut servir Inventory ?</strong></summary>

<li><strong>Organisation de collections</strong> : Classement et gestion avec les Pockets</li>
<li><strong>Travail collaboratif</strong> : Coopération en équipe via le journal partagé</li>
</ul>
Découvrez plus d'idées dans <a href="/inventory/usecases/">100 façons d'utiliser Inventory</a> !

</details>
